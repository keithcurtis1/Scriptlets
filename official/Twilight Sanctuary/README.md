# Twilight Sanctuary

This scriptlet helps users run the Twilight Sanctuary feature of Twilight Domain Clerics in 5e and 5.5e D&D.
It provides a control panel which displays the HP and TempHP of all defined party memebrs and lets the
cleric "top them off" and the end of their turn. This will work on any combination of 5e and 5.5e characters.
The code has instructions on commenting out the current HP display if a DM does not want their player to have that information.

Type `!twilight` in chat to open the menu. All features are menu-driven.

---

### Menu Reference

| Command / Action | Description |
| :--- | :--- |
| **Set Cleric** | Select your Twilight Cleric token on the map first, then click **Set Cleric** to register them. |
| **Track Target** | Target an ally to add them to the tracked list so you can apply Twilight Sanctuary temp HP to them. |
| **Apply** | Rolls $1\text{d}6 + \text{cleric level}$ and applies the result as temp HP to that ally. Both players are notified by whisper. |
| **X** | Remove an ally from the tracked list. |
| **Aura** | Toggle the 30ft visual aura on your cleric token. Select the cleric token on the map first. |

---

> 💡 **Tip:** Hover over the cleric's name in the menu to verify the level source and formula currently in use.
